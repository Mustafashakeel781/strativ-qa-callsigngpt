# Strativ CallSignGPT QA

## Overview

This repository contains QA test design and evaluation documentation for CallSignGPT.

CallSignGPT requires conventional SaaS testing as well as AI-specific evaluation.

## Test Areas

- Registration and authentication
- Sessions and logout
- Chat input validation
- Conversations
- SSE streaming
- Network interruption and recovery
- Responsive behaviour
- Pricing and account access
- API testing
- AI response evaluation

## QA Evidence

- Conventional test scenarios
- Detailed test cases
- SSE test scenarios
- AI evaluation prompts
- Exploratory testing
- Regression suite
- Test summary

## Important Distinction

Software defects and AI-quality observations are recorded separately.

Only behaviour personally observed during testing is reported as an actual defect.
